# 八爪鱼 6 Pro Switch 震动实验

这是为飞智八爪鱼 6 Pro 制作的非官方 Switch 震动实验固件。它尝试让手柄在 Switch 游戏中表现出更丰富的震动频率和细节，尽可能还原HD震动的效果。

本方案尝试保留游戏传来的频率和力度信息，在手柄内部合成对应波形，交给握把音圈马达播放。实际效果因游戏和场景而异，实际震动效果与原厂震动存在一定差异。

配套工具可安装此实验版，也可恢复随工具提供的飞智官方主控 9.0.6.8 与 Switch 组件 0.1.1.1。仅针对已确认的八爪鱼 6 Pro 型号 152；其他型号和固件组合未验证。

这是非官方实验项目，刷写有使手柄无法使用的风险，恢复功能也不能保证在所有故障下可用。实验使用了 NS-LIB-HID 的 CC BY-NC 4.0 代码；固件和部分升级组件涉及第三方权利，公开分发前需要核对授权。
